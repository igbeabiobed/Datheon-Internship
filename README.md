# Superstore Retail Sales – Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Superstore Retail Sales dataset using Python.

The analysis focuses on identifying sales trends, customer purchasing behavior, product category performance, regional sales distribution, and discount sensitivity.

## Project Objectives

- Perform data cleaning and wrangling.
- Identify and handle missing values.
- Analyze customer purchase volume.
- Examine monthly sales seasonality.
- Investigate category-wise revenue and profit.
- Compare regional and customer-segment performance.
- Analyze the relationship between discounts and profitability.
- Develop business insights and recommendations.

## Tools and Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Structure

- `Superstore_Retail_Sales_EDA.ipynb`: Main analysis notebook.
- `superstore_sales.csv`: Original dataset, if included.
- `outputs/`: Supporting cleaned data and analysis outputs.

## Key Areas of Analysis

1. Data cleaning and missing-value profiling.
2. Customer purchase volume.
3. Monthly sales trends and seasonality.
4. Product category revenue and profitability.
5. Regional and customer-segment analysis.
6. Discount sensitivity analysis.

## Business Findings

The project presents five executive findings based on the results of the exploratory analysis, with recommendations for improving sales performance and profitability.

## Conclusion

This project demonstrates the application of Python-based data analysis techniques to identify commercial patterns and support evidence-based retail business decisions.
